# 2026-08-15 카드 이미지 프롬프트

`data/2026-08-15.json` 의 빈 이미지 슬롯을 채우기 위한 생성 프롬프트 모음.
생성한 파일은 `assets/` 에 저장하고 JSON의 해당 필드에 상대경로를 적으면 된다.

## 슬롯 규격 (template.html.j2 기준)

| 필드 | 실제 렌더 크기 | 권장 생성 비율 | 배경 |
|---|---|---|---|
| `headline.image` | 가로 전체 × 320px, `cover` | 16:9 (예: 1600×900) | 사진 |
| `sub_articles[].image` | 가로 전체 × 110px, `cover` | 3:1 (예: 1500×500) | 그라데이션 배너 |
| `core_news.image` | 폭 108px | 1:1 | 투명 PNG |
| `summary_image` | 폭 64px | 1:1 | 투명 PNG |
| `must_read_image` | 30×30px, `contain` | 1:1 | 투명 PNG |

`cover` 로 잘리므로 **주요 피사체는 화면 중앙 가로 띠 안에** 두고, 위아래는 여백으로 둔다.

## 적용 방법

```bash
# 생성한 이미지를 assets/ 에 저장한 뒤
#   assets/2026-08-15-headline.png
#   assets/2026-08-15-yongsan.png
#   assets/2026-08-15-robot.png
python3 render.py data/2026-08-15.json
```

JSON에서 채울 위치:

```json
"headline":      { "image": "assets/2026-08-15-headline.png" },
"sub_articles":  [ { "image": "assets/2026-08-15-yongsan.png" },
                   { "image": "assets/2026-08-15-robot.png" } ]
```
