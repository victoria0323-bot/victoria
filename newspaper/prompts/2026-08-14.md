# 2026-08-14 이미지 생성 프롬프트

8·13 부동산 공급대책 1면 기준. 생성한 파일은 `newspaper/assets/`에 저장하고
`data/2026-08-14.json`의 해당 필드에 경로를 넣은 뒤 다시 렌더링한다.

| 슬롯 | JSON 필드 | 실제 표시 크기 | 권장 생성 크기 |
|---|---|---|---|
| 헤드라인 대형 사진 | `headline.image` | 약 960 × 320 (가로로 잘림) | 1536 × 1024 (3:2) |
| 보조기사 배너 ×2 | `sub_articles[].image` | 약 350 × 110 (가로로 잘림) | 1280 × 540 |
| 핵심뉴스 삽화 | `core_news.image` | 108px 폭 | 512 × 512, 투명 배경 |
| 꼭 봐야 할 기사 뱃지 | `must_read_image` | 30 × 30 | 256 × 256, 투명 배경 |
| 한 줄 요약 아이콘 | `summary_image` | 64px 폭 | 256 × 256, 투명 배경 |

> `background-size:cover`로 중앙을 잘라 쓰기 때문에, **주요 피사체는 항상 화면 정중앙 가로 띠 안**에 두고
> 위아래는 여백으로 비워둔다.

## 1. 헤드라인 사진 — 그린벨트 해제 '미니 신도시' 예정지

```
경기 남양주 외곽 그린벨트 지역을 드론으로 촬영한 항공 사진.
화면 앞쪽에는 여름의 초록빛 논밭과 비닐하우스, 야트막한 야산과 저층 마을이 펼쳐지고,
화면 뒤쪽으로는 강줄기와 고층 아파트 단지 스카이라인, 옅은 산등성이가 층층이 이어진다.
개발 전 농지와 이미 개발된 신도시가 한 화면에서 맞닿아 있는 대비가 보이도록 구성.
8월 한낮의 맑은 자연광, 은은한 대기 원근, 높은 디테일의 사실적인 신문 1면 보도사진 톤.
가로 3:2 구도, 수평선은 화면 위쪽 1/3 지점.
사람 얼굴 없음, 글자·로고·워터마크 없음, 과장된 HDR·필터 없음.
```

**네거티브:** `텍스트, 워터마크, 로고, 일러스트풍, 만화체, 얼굴 클로즈업, 뒤틀린 건물, 과채도`

## 2. 보조기사 배너 ① — KDB생명, 한국투자금융지주 인수

기존 보조기사 이미지와 같은 **두꺼운 검정 외곽선의 볼드 벡터 카툰** 스타일로 통일.

```
가로로 긴 배너 일러스트. 두꺼운 짙은 남색 외곽선의 볼드한 벡터 카툰 스타일,
광택 하이라이트와 부드러운 그라데이션 배경(딥 네이비 → 스틸 블루).
왼쪽에는 파란 우산이 가족을 감싸는 생명보험 심볼, 가운데에는 두 손이 맞잡은 악수,
오른쪽에는 유리창이 늘어선 금융 본사 빌딩과 위로 쌓이는 금화 더미.
빌딩 뒤로 상승하는 얇은 화살표 그래프.
아이콘들은 화면 중앙 가로 띠 안에 정렬, 위아래는 여백.
글자 없음, 사람 얼굴 디테일 없음, 배경 단순하게.
```

## 3. 보조기사 배너 ② — 호남 반도체팹 산업용 전기요금 인하

```
가로로 긴 배너 일러스트. 두꺼운 검정 외곽선의 볼드한 벡터 카툰 스타일,
광택 하이라이트와 따뜻한 앰버 → 딥 옐로 그라데이션 배경.
왼쪽에는 무지갯빛으로 빛나는 반도체 웨이퍼와 회로 패턴이 새겨진 사각 칩,
가운데에는 굵은 노란 번개 아이콘, 오른쪽에는 송전탑과 팽팽한 전선,
아래쪽에 아래로 꺾이는 파란 화살표로 요금 인하 뉘앙스.
아이콘들은 화면 중앙 가로 띠 안에 정렬, 위아래는 여백.
글자·숫자 없음, 배경 단순하게.
```

## 4. 핵심뉴스 삽화 (108px) — 수도권 주택 공급

```
정사각형 미니 스티커 일러스트, 투명 배경.
초록 잔디 위에 지어지는 파스텔 톤 아파트 단지 3동, 앞에 작은 크레인 한 대,
옆에 열쇠가 꽂힌 작은 집 아이콘.
두꺼운 외곽선의 귀여운 플랫 벡터, 파랑·민트·크림 색조, 부드러운 그림자.
글자 없음, 배경 요소 없음.
```

## 5. 꼭 봐야 할 기사 뱃지 (30px) — 선택

```
아주 단순한 미니 아이콘, 투명 배경. 접힌 신문 한 부 위에 돋보기가 겹쳐진 모습.
두꺼운 외곽선의 플랫 벡터, 남색과 노랑 두 가지 색만 사용, 30px로 줄여도 알아볼 수 있게
디테일 최소화. 글자 없음.
```

## 6. 한 줄 요약 아이콘 (64px) — 선택

```
정사각형 미니 아이콘, 투명 배경. 노란 전구 옆에 펼쳐진 노트와 연필,
노트 위에는 글자 대신 짧은 선 세 줄.
두꺼운 외곽선의 귀여운 플랫 벡터, 노랑·남색·크림 색조, 부드러운 그림자. 글자 없음.
```
